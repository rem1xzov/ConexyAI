# Задача для агента: в проекте нет тестов — напиши их и прогони

Проект **Биокомпас** (ASP.NET Core Minimal API + xUnit). Тестовый проект
`tests/BiocompassAI.Tests` существует, но тестов в нём нет: `dotnet test` возвращает
exit code 0 и «нет доступных тестов» — это тихий зелёный прогон.

В проекте уже есть:
- `tests/BiocompassAI.Tests/GoldenQueries.cs` — 20 эталонных запросов с `ExpectedIds`;
- `tests/BiocompassAI.Tests/TestDoubles.cs` — заглушки провайдеров;
- `src/BiocompassAI.Api/Services/QueryNormalizer.cs` — разбор запроса;
- `src/BiocompassAI.Api/Services/HybridSearchService.cs` — поиск и фильтры;
- `src/BiocompassAI.Api/Catalog/CatalogSeeder.cs` — встроенный каталог.

## Что нужно

1. Прочитай контракты и сигнатуры, которые нужны тесту (не угадывай).
2. Напиши `tests/BiocompassAI.Tests/RecallTests.cs`: xUnit-тест(ы) на recall@5 по
   `GoldenQueries.All` **без сети и без БД** — на заглушках и встроенном каталоге.
   Тест должен быть детерминированным и падать, если качество поиска действительно
   упало (не подгоняй ожидания под текущее поведение: если recall ниже ожидаемого —
   так и оставь красным и объясни).
3. Прогони `dotnet test tests/BiocompassAI.Tests` и покажи **фактическое** число
   прошедших и упавших тестов (не «exit code 0»).
4. Если по ходу найден баг в нормализации/поиске — исправь его в `src/`, объясни
   причину и снова прогони тесты.

## Ограничения

- Никаких новых пакетов и внешних сервисов.
- Не отключай и не переписывай golden-данные под свой тест.
- Итог — коротко: что добавил, что прошло/упало, какие правки в `src/`.
